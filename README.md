# mammi

[Открыть сайт mammi](https://wdyueersc696-ai.github.io/mammi/)

Витрина варежек и зимних чехлов на коляску. Статический сайт отображает восемь сочетаний изделий и принтов и демонстрирует форму предзаказа. Посетителю доступен только демонстрационный адрес. Выбор показывается в браузере и в магазин не отправляется.

Карточка изделия сначала открывает описание и планируемые материалы, затем пример формы. Размеры и окончательный состав пока не подтверждены образцами. Главный слоган сохраняется до выбора владельцем нового текста.

Заголовки набраны локальным шрифтом Yeseva One, основной текст — Inter. Файлы шрифтов и лицензии SIL Open Font License находятся в `fonts/`. Фон блока чехлов — `#F3DFB5`, общий фон и красная шапка сохранены.

Готовая страница находится в корне репозитория. Для GitHub Pages источником служат ветка `main` и папка `/ (root)`. Файлы подключены относительными путями, поэтому сайт можно разместить в подкаталоге.

Исходные компоненты и стили лежат в `src/`, фотографии изделий — в `products/`. После изменений выполните `npm ci` и `npm run build`, затем сохраните в репозитории обновлённые `index.html` и `assets/`. Для локальной проверки запустите `python -m http.server 8000` в папке проекта и откройте `http://localhost:8000/`.
